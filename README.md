# WineGuard

Projeto acadêmico de monitoramento de vinícolas com ESP32, FIWARE e painel web.

## Organização planejada

- frontend/: painel React e configuração da Vercel.
- backend/: API Java, PostgreSQL e migrações.
- firmware/: código do ESP32.
- infra/: infraestrutura FIWARE e MQTT.
- docs/: documentação e evidências de integração.

Os componentes estão sendo reunidos neste repositório.
As instruções de cada componente ficarão em sua respectiva pasta.
